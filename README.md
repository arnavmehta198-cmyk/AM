# Arnav Mehta — Personal Website

Source for [arnavmehta.org](https://www.arnavmehta.org/), the personal site of **Arnav Mehta** — creative technologist building AI-powered websites and immersive digital experiences.

## Stack

- [Vite](https://vitejs.dev/) + vanilla JS/React for the interactive pieces
- [Three.js](https://threejs.org/) / [React Three Fiber](https://docs.pmnd.rs/react-three-fiber) for the 3D hero and business card
- [Supabase](https://supabase.com/) for the contact-form backend
- Deployed on [Vercel](https://vercel.com/)

## Development

```bash
npm install
npm run dev      # http://localhost:8080
npm run build    # production build to dist/
npm run preview  # serve the production build locally
```
